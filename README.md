Версия 0.4
🎨 Цветной вывод шагов

Каждый тип сообщения выделен своим цветом в терминале
💭 Рассуждение (thought) — жёлтый
⚡ Инструменты (tools) — синий
✅ Финальный ответ (answer) — зелёный
⏳ Ожидание (wait) — серый
Реализовано через словарь _C с ANSI-кодами, совместим с colorama на Windows

📊 Счётчик токенов

После каждого ответа выводится: сколько токенов сгенерировано, потрачено на промпт и суммарно за сессию
Данные берутся из полей eval_count и prompt_eval_count ответа Ollama
Команда токены / tokens — показать статистику в любой момент
При выходе (exit) итоговая статистика выводится автоматически

📤 Экспорт диалога

Команда export сохраняет диалог сессии в Markdown-файл
Имя файла формируется автоматически: export_YYYY-MM-DD_HH-MM-SS.md
Файл содержит все реплики с временными метками и иконками ролей

🔁 Команда Retry

Команды ретрай / retry / повтори повторяют последний вопрос без перепечатки
Полезно если ответ не устроил или Ollama вернула неполный результат

⚙️ Конфигурация через .env

Все ключевые параметры вынесены из кода в переменные окружения
Поддерживается файл .env через python-dotenv
Настраиваемые параметры:

envOLLAMA_URL=http://localhost:11434
LLM_MODEL=llama3
LLM_TIMEOUT=90
SANDBOX_TIMEOUT=15
CACHE_TTL_SEARCH=300
CACHE_TTL_BROWSE=600
CACHE_TTL_FILE=60
MAX_RAG_RESULTS=4
🪟 Поддержка Windows 10

Добавлена интеграция с colorama для корректного отображения ANSI-цветов в CMD и PowerShell
colorama.init(autoreset=True) вызывается автоматически при старте
При отсутствии colorama агент продолжает работу без цветов


Версия 0.3
🧠 RAG — Долгосрочная векторная память

Агент помнит факты между перезапусками — данные сохраняются в agent_rag_memory.json
Эмбеддинги генерируются через Ollama /api/embeddings, поиск по косинусному сходству
При каждом запросе автоматически подбираются top-4 релевантных воспоминания и вставляются в промпт
Агент сам вызывает инструмент remember когда узнаёт важный факт о пользователе
Новые команды: память, запомни <факт>, забудь <номер>

🐍 Инструмент run_python — Выполнение кода

Агент пишет Python-код и запускает его в изолированном дочернем процессе
Таймаут 15 секунд — зависший код автоматически прерывается
Базовый фильтр блокирует опасные операции: os.system, subprocess, сетевые вызовы, запись файлов
Агент получает stdout, stderr и код возврата

🌐 Инструмент browse — Чтение веб-страниц

Полное чтение страницы по URL через requests + BeautifulSoup
Автоматически вырезает скрипты, стили, навигацию и футеры — только чистый текст
Лимит 6000 символов с флагом truncated

⚡ Стриминг токенов

Ответы выводятся по мере генерации, не нужно ждать полного ответа
Реализован через Ollama stream: true с построчным разбором NDJSON

🔁 Exponential Backoff — Устойчивость к сбоям

При недоступности Ollama агент ждёт 1 → 2 → 4 секунды и повторяет запрос (3 попытки)
Агент не падает при временных сетевых ошибках

🗄️ TTL-кэш инструментов

Одинаковые вызовы инструментов не повторяются в течение сессии
Поиск кэшируется на 5 минут, страницы — 10 минут, файлы — 1 минута
Ключ кэша — sha256 от имени инструмента + аргументов (потокобезопасно)
Команда clear cache для сброса
